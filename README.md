# demo

一个轻量的公开示例仓库，用来熟悉 Git 工作流：浏览文件、查看历史、在本地做小幅修改。

## 克隆

```bash
git clone https://github.com/abcdok/demo.git
```

## 目录

| 路径 | 说明 |
|------|------|
| `src/` | 示例 TypeScript 源码 |
| `docs/` | Markdown 文档 |
| `config/` | 示例 JSON 配置 |
| `samples/` | 可随意改动的笔记文件 |

## 随便试试

- 打开 `docs/guide.md` 看排版与代码块  
- 改一行 `samples/note.md`，用 `git diff` 看变更  
- 在 `src/` 里走读 `greet` 与 `formatTitle`
